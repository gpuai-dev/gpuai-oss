# gpuai-sdk
The HTTP API served by a self-hosted GPU.ai Open Source server (`gpuctl`).
It provisions GPU instances from the suppliers the operator has
configured, tracks their lifecycle, and manages the SSH keys and registry
credentials used at launch.

Authenticate with `Authorization: Bearer <api key>`. Keys are created on
the server with `gpuctl apikey create --name <name>`.

The server URL below is the default for a local deployment. Point clients
at wherever your gpuctl server listens; the CLI, SDKs and MCP server all
take the base URL as configuration.
