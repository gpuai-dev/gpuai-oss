# Code of Conduct

GPU.ai Open Source has adopted the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in the project:
in issues, pull requests, discussions and any other project space.

In short: be respectful, assume good intent, accept constructive feedback,
and do not harass anyone.

## Reporting

Report unacceptable behaviour privately to **support@gpu.ai**, the project's private contact address. Reports are reviewed
promptly and kept confidential. The project maintainers will act on them
following the enforcement guidelines in the Contributor Covenant.
